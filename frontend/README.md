# MNC Resume Studio — Frontend

React + Vite frontend for the MNC Resume Studio full-stack school project.

## Pages
### Candidate
- Dashboard
- Jobs
- My Applications
- My Resume
- Profile
- Settings

### Admin
- Admin Dashboard
- Users Management
- Job Management
- Application Management
- Activity Log

## Run
```bash
npm install
npm run dev
```

The frontend expects Laravel at `http://127.0.0.1:8000/api` by default. You can override it with `VITE_API_URL`.
